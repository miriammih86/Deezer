# Deezer
Trabalho acadêmico sobre o aplicativo Deezer

#Descrição
O Deezer é um serviço de Streaming de áudio, que está disponível para mais de 180 países e que atualmente possui mais de 90 milhões de músicas. É uma empresa que tem sede em Paris. Atualmente ele possui mais de 16 milhões de usuários ativos mensalmente ao redor do mundo. 
Ela possui duas versões, sendo uma a gratuita que tem publicidades e restrições e a outra que é paga e não tem publicidades nem restrições. 

#Público-Alvo
O público-alvo do Deezer é formado principalmente por jovens e adultos que gostam de ouvir música e podcasts pela internet. A plataforma é voltada para pessoas que utilizam bastante o celular e outros dispositivos eletrônicos para ter entretenimento.

Entre seus principais usuários estão pessoas que procuram variedade de músicas, playlists personalizadas, descobertas de novos artistas e praticidade. O Deezer também atende diferentes estilos musicais e perfis de consumidores, desde quem escuta música casualmente até quem é apaixonado por música e utiliza o serviço diariamente.

De forma geral, podemos definir o público-alvo do Deezer como pessoas conectadas, interessadas em música e entretenimento digital, principalmente jovens e adultos.

#Funcionalidades
As principais funcionalidades do Deezer são:

Ouvir músicas;
Ouvir podcasts;
Pesquisar músicas;
Pesquisar artistas;
Pesquisar álbuns;
Criar playlists;
Editar playlists;
Compartilhar músicas e playlists;
Salvar músicas na biblioteca;
Receber recomendações de músicas;
Descobrir novos artistas;
Baixar músicas para ouvir offline em planos que possuem essa opção;
Utilizar o aplicativo em diferentes dispositivos.

#Tecnologias Utilizadas
JavaScript — utilizada principalmente no desenvolvimento da interface web e funcionalidades interativas.
TypeScript — usada em aplicações modernas para melhorar a organização e segurança do código.
Python — muito utilizada em inteligência artificial, machine learning, análise de dados e sistemas de recomendação.
Java — pode ser utilizada em sistemas de backend e serviços que precisam lidar com grande quantidade de usuários.
C/C++ — podem ser utilizadas em partes que exigem alto desempenho, como processamento de áudio.
Swift — utilizada no desenvolvimento de aplicativos para dispositivos iOS.
Kotlin/Java — utilizadas no desenvolvimento de aplicativos para Android.

#Requisitos Técnicos
Android
Para a versão atual do aplicativo Android, o requisito mínimo é:

Sistema operacional: Android 8.0 ou superior.
Versão: o aparelho precisa ser compatível com a versão atual do aplicativo e possuir Google Play Store.

iPhone e iPad
Atualmente, a App Store brasileira informa:

iPhone: iOS 18.5 ou superior.
iPad: iPadOS 18.5 ou superior.

Computador
No computador, existem duas formas principais de utilizar o Deezer:

Navegador: acessar o Deezer pela internet, sem necessariamente instalar o aplicativo.
Aplicativo para desktop: disponível para Windows e macOS. A própria comunidade oficial do Deezer disponibiliza os caminhos para download dessas versões.
